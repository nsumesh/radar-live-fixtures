# radar-live-fixtures

Static HTML fixtures used to exercise an automated change-monitoring pipeline end to end.

Everything here is **synthetic**. The "Meridian Markets Authority" is an invented body and the
"Digital Asset Markets Regulation" does not exist. The pages are fabricated content written to give a
monitoring system something stable to read, and to give a source edit something observable to detect.
They are not regulatory publications, they describe no real legal obligation, and they should not be
cited for anything.

Served via GitHub Pages so the pipeline fetches them over a public URL, the same way it would fetch a
real source.
